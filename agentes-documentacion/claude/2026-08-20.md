## Estructura de la Base de Datos
### Auth Users (Supabase Auth)
- 4 usuarios creados vía Admin API
- Profiles creados manualmente via Management API SQL

### Tablas Principales
- `profiles` - Perfiles de usuario (id, email, role, full_name, is_active)
- `cases` - Casos de la Defensoría (case_number auto: DP-YYYY-NNNNNN)
- `conversations` - Conversaciones del chat IA
- `messages` - Mensajes del chat

## Edge Functions Desplegadas
- `chat-ai` - API de chat con OpenAI (soporte anónimo y autenticado)
- `process-case` - Procesamiento de casos con IA
- `transcribe-audio` - Transcripción de audio via Whisper
